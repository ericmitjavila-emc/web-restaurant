# Web Restaurant - La Taula d'en Marc 🍽️

## Descripció
Pàgina web completa per a un restaurant català amb carta interactiva, 
informació del local i dades de contacte.

## Context
Projecte personal realitzat per aprendre desenvolupament web des de zero.
M'interessava crear una web real i funcional, i vaig triar un restaurant 
perquè és un tipus de negoci amb molt contingut visual i estructura clara.

## Tecnologies usades
- HTML5
- CSS3 (disseny responsive, animacions)
- Google Fonts

## Contingut de la web
- Pàgina principal amb hero visual
- Carta de plats amb categories i preus
- Secció "La nostra història" amb estadístiques
- Pàgina de contacte amb horaris i adreça

## Com executar-lo
Descarrega l'arxiu `index.html` i `style.css` i obre'l amb qualsevol navegador web.
No necessita cap instal·lació ni servidor.
